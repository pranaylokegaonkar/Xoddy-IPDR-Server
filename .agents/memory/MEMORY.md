- [Flow archive compression](flow-archive-compression.md) — gzip payload + archived-flag must be one transaction over a frozen row-id set, or payload and archived rows drift.

- [Bulk delete on a live-ingest table](bulk-delete-live-table.md) — background bulk deletes over a continuously-written table must snapshot an id cutoff at start, or they never terminate and silently destroy post-start records.
- [flow_records unbounded growth & dashboard query cost](flow-records-unbounded-growth.md) — compression never deletes rows, so dashboard aggregates must be time-scoped + indexed or they full-scan and 504 in prod.
- [Archive 2-hour windowing](archive-windowing.md) — archives bucket by fixed IST 2h clock windows (by end_time, half-open, 15-min grace); duplicate late-arrival archives are intentional (never drop IPDR records).
- [Drizzle inArray at scale](drizzle-inarray-scale.md) — a huge id list to inArray crashes the SQL builder + busts Postgres's 65535 param limit; use a subquery for deletes, chunked exact ids for frozen-set updates.
- [Orval path+query param collision](orval-path-query-param-collision.md) — never mix a path param and a query param on one OpenAPI op (TS2308 dup export); use a path-only sub-route instead.
- [Periodic job scheduling on restart-prone hosts](compression-scheduler.md) — one long setInterval resets on every restart and never fires; use a short poll gated by a cheap indexed readiness check + a startup kick.
- [orval query options](orval-query-options.md) — generated useGetX hooks need an explicit queryKey (via getGetXQueryKey) whenever you pass a query options object, else TS2741.
- [Ubuntu update environment](ubuntu-update-environment.md) — the updater must use the running service's environment, not assume a second env file targets the same database.
- [pnpm approval compatibility](pnpm-build-approvals.md) — newer pnpm can append build-approval placeholders, leaving a successful update's checkout dirty and blocking the next release.
- [Archive list performance](archive-list-performance.md) — few archive rows can still contain huge payloads; list metadata without fetching compressed contents.
- [Destructive-job uncertainty](destructive-job-uncertainty.md) — a timeout or vanished progress is an unknown outcome; never claim success or blindly repeat a deletion.
- [Historical archive search](historical-archive-search.md) — Old Search uses isolated temporary copies; never restore archived records into the live flow table merely to search them.
